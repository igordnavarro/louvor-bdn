Política de Privacidade — Worship Church

Última atualização: 3 de novembro de 2026.

O Worship Church é um app gratuito para equipes de louvor organizarem cifras, tom, BPM, pads, playlists e medleys. Ele funciona no navegador e guarda seus dados no próprio aparelho.

Login com Google

O login com Google é opcional e serve só para sincronizar seus dados entre aparelhos. Quando você entra, o app pede permissão para:

  • ver seu nome e e-mail, para mostrar qual conta está conectada;
  • guardar um arquivo do próprio app na pasta oculta de dados do app no seu Google Drive (drive.appdata).

O app não vê, lê ou altera nenhum outro arquivo do seu Google Drive. O arquivo de sincronização contém apenas os dados que você criou no app: ajustes de tom, capotraste e BPM, letras editadas, anotações, medleys, playlists, favoritas e nomes de usuários do app.

Onde os dados ficam

Os dados ficam no seu aparelho e, se você entrar com Google, no seu próprio Google Drive. Não existe servidor do Worship Church: nenhum dado é enviado para os desenvolvedores nem compartilhado ou vendido para terceiros.

Como apagar

Use “Sair” no app para desconectar a conta. Para apagar o arquivo de sincronização, acesse o Google Drive → Configurações → Gerenciar apps → Worship Church → Excluir dados de apps ocultos. Você também pode revogar o acesso em myaccount.google.com/permissions.
